| Function Name | Where I used it | What it does in my own words | Official Documentation Link |
| `PDO::prepare()` | In all Repository files (like `findById` and `create`). | It readies the SQL query before running it. I used it so hackers can't do SQL injection because it separates the SQL code from the user input. | [PDO::prepare](https://www.php.net/manual/en/pdo.prepare.php) |
| `PDOStatement::execute()` | In all Repository files. | It actually runs the query that we prepared. It takes the array of variables and puts them in the query safely. | [PDOStatement::execute](https://www.php.net/manual/en/pdostatement.execute.php) |
| `PDOStatement::fetch()` | In `findById()` functions. | It brings only one row from the database. I use it when I need to find just one employee or one laptop by ID. | [PDOStatement::fetch](https://www.php.net/manual/en/pdostatement.fetch.php) |
| `PDOStatement::fetchAll()` | In `findAll()` functions. | It gets all the rows from the database and gives them back as an array. I use it for list pages to show everything in tables. | [PDOStatement::fetchall](https://www.php.net/manual/en/pdostatement.fetchall.php) |
| `PDOStatement::rowCount()` | In `update()` and `delete()` functions. | It tells me how many rows were changed or deleted. I check this to see if my update or delete actually worked. | [PDOStatement::rowcount](https://www.php.net/manual/en/pdostatement.rowcount.php) |
| `PDO::lastInsertId()` | In `addProject()` inside `ProjectRepository`. | It gives back the ID of the last thing I added to the database. I used it when creating a project to get its new ID so I can link the leader to it. | [PDO::lastinsertid](https://www.php.net/manual/en/pdo.lastinsertid.php) |
| `PDO::beginTransaction()` | In Service files (like adding an employee). | It stops the database from saving immediately. It starts a safe area so I can do many queries together without breaking data. | [PDO::begintransaction](https://www.php.net/manual/en/pdo.begintransaction.php) |
| `PDO::commit()` | In Service files at the end of `try`. | It saves all the queries I did after beginTransaction. If everything is good, it pushes them to the database. | [PDO::commit](https://www.php.net/manual/en/pdo.commit.php) |
| `PDO::rollBack()` | In Service files inside `catch`. | If something goes wrong in the try block, this cancels all the queries so the database doesn't get messed up. | [PDO::rollback](https://www.php.net/manual/en/pdo.rollback.php) |
